# projeto-contatos
Sistema de Gerenciamento de Contatos (PT-BR) – Primeira Versão (02/09/2026)

Projeto desenvolvido em Python para praticar estruturas condicionais, loops, funções, dicionários, tratamento de exceções e operações CRUD.

Funcionalidades:
Pesquisar contato por nome ou número
Adicionar contato;
Editar contato;
Excluir contato;
Listar contatos;
Validação de entradas;
Prevenção de contatos duplicados.
